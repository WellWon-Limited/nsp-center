## Карточка проекта

- **Что и для кого:** сайт магазина продукции Nature's Sunshine (NSP) для
  покупателей nsp-center.ru, дальше — PWA; плюс прототип мобильного приложения.
- **Типы:** сайт (web). Сервер `scripts/serve.mjs` только отдаёт готовые
  страницы, без базы и входа, поэтому отдельный тип «сервер» не применялся.
- **Где хранится:** GitHub, закрытый репозиторий WellWon-Limited/nsp-center;
  ветка `main` защищена, правки через запрос на слияние.
- **Запуск и проверка:** `npm run build`, `npm run preview` (порт 5217);
  проверка — `npm run check`, она же в GitHub перед слиянием.
- **Куда выкатывается:** каждое слияние в `main` само выкатывается на тестовый
  сервер https://nsp-center.dev.codimax.ru. Боевой nsp-center.ru — пока чужой
  сайт, с которого сделан снимок.
