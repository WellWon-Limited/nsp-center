## Карточка проекта

- **Что и для кого:** сайт магазина продукции Nature's Sunshine (NSP) для
  покупателей nsp-center.ru, дальше — PWA; плюс прототип мобильного приложения.
- **Типы:** сайт (web). Сервер `scripts/serve.mjs` только отдаёт готовые
  страницы, без базы и входа, поэтому отдельный тип «сервер» не применялся.
- **Где хранится:** GitHub, закрытый репозиторий WellWon-Limited/nsp-center;
  ветка `main` защищена, правки через запрос на слияние.
- **Запуск и проверка:** `npm run build`, `npm run preview` (порт 5217);
  проверка — `npm run check`, она же в GitHub перед слиянием.
- **Куда выкатывается:** каждое слияние в `main` само выкатывается на тестовый
  сервер https://nsp-center.dev.codimax.ru. Боевой nsp-center.ru — пока чужой
  сайт, с которого сделан снимок.

история чистая, секретов нет, проверки запускаются одной командой и

## Что сломано или рискованно

**В правилах проекта нет запрета на необратимые действия без «да»** (R2, высокая)
Сейчас так: `AGENTS.md` разрешает самостоятельное слияние запроса после зелёных
проверок, а слияние в `main` сразу выкатывает тестовый сервер. Правило «сначала
спросить владельца» живёт только в общих правилах на вашем Маке. Из-за этого:
агент коллеги на другом компьютере сольёт и выкатит без вопроса. Сделать:
строка в `AGENTS.md` (решение 1). Цена: 5 минут. Кто: нужно ваше «да».

**Тестовый сервер открыт для поисковиков** (W9, высокая для SEO)
Сейчас так: https://nsp-center.dev.codimax.ru/robots.txt разрешает индексацию
всего сайта. Из-за этого: Яндекс может найти тестовую копию и посчитать её
дублем — боевому сайту будет труднее подняться в поиске. Сделать: решение 3.
Цена: 30 минут. Кто: нужно ваше «да» (меняется настройка выкатки).

**Большой файл в истории** (G4, средняя)
Сейчас так: `references/nsp-center.ru/data/pages.jsonl` — 8,4 МБ (порог
стандарта — 5 МБ), весь архив репозитория — 128 МБ из-за снимка с картинками.
Из-за этого: каждое обновление снимка навсегда добавляет ещё столько же.
Сделать: решение 2. Кто: нужно ваше «да».

**Устаревшая постановка в правилах и плане** (A13, D5, средняя)
Сейчас так: `AGENTS.md` говорит «до утверждения первого брифа… выбрать стек»,
а стек выбран и сайт собран; `docs/PLAN.md` называет активным уже выполненный
результат. Сделать: решение 4. Кто: нужно ваше «да».
