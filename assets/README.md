# Ресурсы проекта

Логотипы, иконки, изображения, шрифты и их редактируемые исходники.
Для сторонних ресурсов сохраняйте источник и лицензию; не добавляйте секреты.
Референсы и примеры для сравнения — в references/. Каталог не публикуется
автоматически: подключение ресурсов к приложению определяется его стеком.
