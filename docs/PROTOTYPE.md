# Прототип мобильного приложения NSP

`assets/NSP App Prototype.html` — интерактивный прототип мобильного приложения
NSP Center. Из него взята дизайн-система сайта (`design/systems/nsp/`), и по
нему собраны личные сценарии сайта: план приёма, марафон, анкета, корзина,
профиль. Файл — исходник, его не меняют.

## Откуда он

- Сделан в Claude Design, проект «NSP mobile app designs»
  (https://claude.ai/design/p/a0d6833c-539d-40e9-bcfc-b5d6ad377e7a), в сентябре
  2026 года.
- Стиль «1c — стекло, мягкий свет»: матовые полупрозрачные карточки на
  мятно-голубом фоне. Его выбрали из шести вариантов главной.
- Копия проекта Claude Design (скачана 3 октября 2026) лежит вне репозитория:
  `~/IdeaProjects/design-archive/mcp-account/NSP-mobile-app-designs__a0d6833c/`.
  Файл прототипа там байт в байт тот же.
- SHA-256: `ee22021e1996d17cf75b0dd4a9cbc6ce161aa83cb399711ff3d062dfda73e950`
  (то же значение сверяет `node scripts/extract-prototype.mjs --check`).

Это одна HTML-страница на 1,1 МБ: шрифты, фото наборов и код встроены в неё.
Данные заготовлены, к серверу она не обращается. Страница сама рисует корпус
телефона и подпись «NSP-Center · интерактивный прототип · стиль 1c».

## Что в нём есть

Нижнее меню из пяти разделов:

| Раздел | Что видит пользователь |
|---|---|
| Главная | Приветствие по имени, «Приём на сегодня» с отметками и напоминанием заказать повторно, прогресс марафона «Очистка организма», баннер диагностического теста, наборы с фото, хиты продаж |
| Каталог | Поиск, фильтр по категориям, карточка товара: положить в корзину или добавить в график приёма |
| Консультант | Чат с быстрыми вопросами и полем ввода; ответы заготовлены, но зависят от вопроса: подбор товаров, заказ, скидка, приём, сон |
| Здоровье | Вкладка «Приём» — неделя и график на сегодня; вкладка «Марафон» — сетка из 21 дня и задания, день засчитывается, когда отмечены все задания |
| Профиль | Карта со штрихкодом и уровнями скидки (Стартовая, Серебряная, Золотая, Платиновая), история заказов, настройки |

Сквозные сценарии: корзина считает скидку по уровню карты; оформленный заказ
попадает в историю и начисляет баллы PV, уровень карты может вырасти. Тест из
5 вопросов выдаёт результат по системам организма и курс, который можно
положить в корзину или обсудить с консультантом.

## Как открыть

Прототип отдаёт сервер проекта (`apps/web/server.mjs`) — локально и на
dev-стенде https://nsp-center.dev.codimax.ru. В статическую сборку сайта
(`dist/`) он не попадает:

```sh
npm run build
npm run preview
```

- http://127.0.0.1:5217/app-prototype/ — рабочая версия для фреймов Factory.
- http://127.0.0.1:5217/app-prototype/original/ — исходный файл без изменений,
  для сравнения.

```sh
sh .wellwon/canvas/cv prototype open /app-prototype/ --device iphone-17-pro
```

## Чем рабочая версия отличается от исходника

Исходный файл не меняется. Сервер на лету строит из него рабочую версию
(`scripts/prototype-adapter.mjs`); проверки — `tests/prototype.test.mjs`.

| Было в исходнике | Стало в рабочей версии | Почему |
|---|---|---|
| Нарисованный телефон 390×844 с подписью «NSP-Center · интерактивный прототип · стиль 1c» | Приложение занимает весь экран фрейма | В рамке телефона получался телефон в телефоне |
| Нарисованная строка «9:41» с батарейкой | Строку состояния рисует сама рамка устройства. Фон с градиентом идёт до самого верха, вниз сдвинуто только содержимое | Две строки состояния наслаивались, а сдвиг всего экрана оставлял сверху плоскую полосу без градиента |
| Красная плашка «[bundle] ResizeObserver loop…» внизу экрана | Плашки нет; настоящие ошибки она показывает по-прежнему | Это безобидное предупреждение браузера, а обёртка выгрузки показывала его как ошибку |
| Экраны «Здоровье» и «Профиль» уезжали влево при нажатии | Экран не прокручивается вбок | Размытые пятна фона выходят за правый край на 120 px |
| Наборы в каталоге — пустые карточки | Фото наборов, как на главной | Каталог ссылался на файл из Claude Design, которого нет в выгрузке |

На планшете и ноутбуке приложение показывается колонкой шириной до 440 px по
центру. Фото отдельных товаров в прототипе — заглушки со штриховкой, так
задумано в исходнике.

## Что ещё есть в проекте Claude Design, но не в репозитории

- «NSP Home Options» — шесть вариантов главной (1a–1f), из них выбран 1c.
- «NSP App Details» — 8 элементов приложения по 2–3 варианта: push-уведомления,
  статус доставки на экране блокировки и в «островке», всплывающие сообщения,
  центр уведомлений, виджеты рабочего стола, запрос разрешения на уведомления,
  первый запуск, состояния загрузки, пустого экрана и ошибки. Варианты пока не
  выбраны и в прототип не встроены.

Перенести их на доску «Дизайна» можно командой `cv ds pull` из папки архива.
