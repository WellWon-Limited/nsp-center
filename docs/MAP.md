# Что где лежит

Карта проекта NSP Center: где смотреть сайт и прототип, что лежит в
репозитории и какие материалы хранятся вне его. Состояние на 10 ноября 2026.

## Где смотреть

| Что | Адрес | Когда обновляется |
|---|---|---|
| Сайт локально | http://127.0.0.1:5217/ | После `npm run build` и перезапуска `npm run preview` |
| Управление сайтом локально | http://127.0.0.1:5217/admin/ — вход для сотрудников | Вместе с сайтом; сотрудника создаёт `npm run admin:create -- <почта>` |
| Прототип приложения локально | http://127.0.0.1:5217/app-prototype/ (рабочая версия), `/app-prototype/original/` (исходник) | Сразу при перезапуске сервера, из исходного файла |
| Витрина дизайн-системы локально | http://127.0.0.1:5217/design-system/ | Вместе с сайтом |
| Тестовый сервер (dev-стенд) | https://nsp-center.dev.codimax.ru — те же три адреса | Сам после каждого слияния в `main`, через 5–10 минут |
| Репозиторий | https://github.com/WellWon-Limited/nsp-center, ветка `main` | При каждом слиянии запроса. Закрытый: доступ и порядок правок — [CONTRIBUTING.md](../CONTRIBUTING.md) |
| Боевой сайт магазина | https://nsp-center.ru/ | Не наш код: отсюда сделан снимок, из которого собран сайт |

Порт 5217 закреплён за проектом в реестре портов Factory. Dev-стенд работает на
российском сервере (Coolify WellWon). Как он устроен — в
[разработке](DEVELOPMENT.md#dev-стенд), доступ к самому серверу для выкладки не
нужен.

### Доска «Дизайна» в WellWon Factory

На доске три рамки:

- iPhone 17 Pro и MacBook Air 13 — сайт;
- iPhone 17 Pro — рабочая версия прототипа приложения.

Открыть заново:

```sh
sh .wellwon/canvas/cv prototype open / --device iphone-17-pro
sh .wellwon/canvas/cv prototype open / --device macbook-air-13
sh .wellwon/canvas/cv prototype open /app-prototype/ --device iphone-17-pro --beside
```

Factory узнаёт сайт как прототип проекта по файлу `.wellwon/prototype.json`. Это
настройка этого Мака, в git она не попадает.

## Чего пока нет

- PWA: сайт нельзя установить на телефон, нет офлайн-режима и уведомлений.
- Сервер магазина: оплата, отправка заказов, вход в аккаунт, живой консультант.
  Корзина, профиль и план приёма хранятся только в браузере посетителя.
- Фото отдельных товаров в прототипе — заглушки; настоящие фото есть только на
  сайте.
