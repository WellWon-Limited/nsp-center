# Паспорт NSP Center

Пользователи — посетители NSP Center, которые изучают ассортимент, составы,
документы и материалы о продуктах, сохраняют подборки и связываются с магазином;
сотрудники магазина ведут заказы, товары, курс и отзывы в управлении сайтом.

Подтверждённая задача владельца: собрать полную дизайн-систему из
`assets/NSP App Prototype.html`, построить весь сайт из
`references/nsp-center.ru/` и проверить все сохранённые страницы.

Результат — адаптивный сайт с 334 HTML-документами, покрывающий все 227 исходных
адресов, 4 новых товара и 90 страниц-тем. Источники и свойства сохраняются;
отсутствующий материал не выдумывается. Статический контент доступен до JavaScript,
interactive состояние сохраняется в браузере, у вошедшего — в аккаунте. Сайт
устанавливается как приложение (PWA): план и марафон работают без сети, напоминания
о приёме приходят, пока приложение открыто или свёрнуто. Дизайн-система живёт в
`design/systems/nsp/`, её компоненты использует сайт, витрина — `/design-system/`.

Граница на 11 ноября 2026: есть сервер аккаунтов (Postgres) — регистрация и вход
покупателя, данные аккаунта на любом устройстве, отзывы, управление сайтом для
сотрудников (на dev-стенде базы пока нет). Нет оформления заказа на сайте, оплаты,
отправки заказов в магазин и проверки номера дисконтной карты по базе NSP.
Медицинская диагностика не делается и не планируется. Цены не являются live-feed:
рубли = прайс в у.е. × курс, который задаёт сотрудник. Исходный прототип и снимок
не изменяются.

Нефункциональные требования: mobile safe zones, keyboard/focus,
reduced-motion, содержательные alt, безопасный semantic HTML, воспроизводимый
offline build и независимый source-retention gate. Evidence —
[аудит](CONTENT-AUDIT.md) и [визуальная приёмка](VERIFICATION.md).

## Продукт и направление

Цель — сайт и PWA для продукции Nature's Sunshine Products (NSP) на домене
https://nsp-center.ru/. Направление подтверждено владельцем 2026-11-03; ниже
у каждого пункта — что из него уже сделано.

Что хорошо продаёт и должно стать основой продукта:

- **Консультации.** Посетитель получает разбор своей ситуации, а не только
  каталог. Сделано: чат-помощник `/consultation/`, тест-рекомендации, связь со
  специалистом по телефону и почте.
- **Тематические продажи.** Страница отвечает на вопрос («для чего нужен
  витамин D3») и подводит к подходящим товарам, а не показывает список из
  десяти позиций. Сделано: 90 страниц-тем `/temy/…` с парами «с чем сочетают».
- **Сильный ИИ-агент** на базе курсов нутрициологии: отвечает по материалам
  базы лекций врачей
  (https://drive.google.com/drive/folders/1_RyrfDBliq31siWujvt14huMQKuIKID6),
  ссылается на источник, не ставит диагнозы и не заменяет врача. Сделано: сейчас чат —
  бот без нейросети (отвечает по лекциям и страницам магазина на типовые вопросы
  покупателей); подключение нейросети по ключу готово, но не включено. Подключать ли
  нейросеть — вопрос пока открыт.
- **Дисконтные карты (партнёрская цена).** См. цены и регистрацию ниже.
- **Аккаунты покупателей.** Регистрация и вход — только по российской почте (Яндекс, Mail.ru,
  Рамблер, адреса на .ru, .рф, .su); телефон — необязательное поле для связи. В кабинете: личные
  данные, дисконтная карта, «Мои заказы» и «Мои покупки», избранное, лист ожидания, план приёма.
- **Корзина** по логике маркетплейсов: выбор товаров галочками, доставка и скидка в итоге. Заказ
  пока сохраняется как черновик; оформление и оплата на сайте — следующий шаг.
- **Управление сайтом.** Сотрудники — отдельные аккаунты с отдельным входом `/admin/`, только
  управление (сводка, заказы, товары, курс у.е., отзывы, журнал чата, сотрудники), без личного кабинета.
  Права пока одинаковые; роли — когда появится второй сотрудник.
- **Отзывы и мнения в каждом товаре**, в том числе на основе лекций. Мнение
  из лекции подаётся как экспертный комментарий с указанием врача и лекции;
  отзывы покупателей не выдумываются. Сделано: комментарии экспертов из лекций и
  отзывы покупателей после проверки сотрудником; оценка товара — по настоящим отзывам.

### Цены

У каждого товара две цены:

- **партнёрская** — для партнёров компании, у которых есть ID (дисконтная
  карта);
- **розничная** — без скидки, для всех остальных.

Цены по карте видит только тот, кто вошёл в аккаунт и указал номер дисконтной
карты в профиле; остальным сайт показывает розничные цены и предложение «войдите
или оформите карту» без суммы: дистрибьютор не может выставлять товар всем по цене
дистрибьютора. Номер карты пока не сверяется с базой NSP.

### Что нужно до запуска боевого сайта

- Ответ юриста: допустим ли вход по российской почте по закону 406-ФЗ; продавец в подвале
  сайта и его реквизиты; оферта; отдельный документ согласия на обработку персональных данных.
- Оформление заказа и оплата.
- Проверка на настоящих телефонах.

### Регистрация партнёров

Партнёрский сайт компании — https://nsp25.com. Клиент становится партнёром
(оформляет дисконтную карту) по ссылке с ID спонсора, пример:
https://nsp25.com/signup?sid=446621.

План на потом: клиент заполняет регистрацию в нашем PWA, а наша автоматизация
сама регистрирует его в https://nsp25.com. Способ (API или заполнение формы),
согласие клиента на передачу данных и хранение персональных данных нужно
решить до реализации.
