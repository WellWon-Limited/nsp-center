# Исключение: большой файл снимка в git до 2026-12-31

Решение владельца от 3 ноября 2026 (аудит проекта, пункт G4).

**Что решили.** Файл `references/nsp-center.ru/data/pages.jsonl` (8,4 МБ)
остаётся в git, хотя стандарт аудита считает большим всё, что больше 5 МБ.
Историю git не переписываем.

**Почему.** Снимок сайта nsp-center.ru — источник сборки: из него
`npm run build` получает все 227 страниц, товары и тексты; без файла сайт не
собирается, а проверки сверяют сборку со снимком.

**Отвергнутые варианты.** Git LFS или отдельное хранилище — лишняя
инфраструктура для одного файла, пока снимок не обновляется.

**Срок.** До 2026-12-31 или до первого обновления снимка — что раньше. К сроку
решить: остаётся ли снимок источником содержимого после запуска на боевом
домене; если да — перенести большие файлы в LFS или хранилище; если нет —
заменить снимок новым источником.
