# Цены по дисконтной карте не публикуются

Дистрибьютор не может выставлять товар всем по цене дистрибьютора. Поэтому все страницы, данные в браузере
(`summary.json`, `chat-index.json`) и `/api/site` несут только розничную цену. Цены по карте отдаёт только
`GET /api/card-prices` — вошедшему покупателю с номером карты в профиле или сотруднику; браузер держит их в
памяти и не кэширует. Посетитель без входа видит «Скидка до 30% по дисконтной карте — войдите или оформите
карту», без суммы. Переключатель «У меня есть дисконтная карта» убран.

Ограничение: номер карты пока не сверяется с базой NSP — для этого нужен её API.

Код: `scripts/card-prices.mjs`, `src/site.ts` (`applySite`, `CardPrices`), `src/store.tsx`.
Проверки: `tests/card-prices.test.mjs`, `tests/accounts.test.mjs`. Решение владельца 2026-11-10.
