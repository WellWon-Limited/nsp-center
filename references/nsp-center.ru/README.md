# Снимок сайта nsp-center.ru

Источник: https://nsp-center.ru/ (собственный сайт владельца проекта).
Снят 2026-09-26 скриптом [`scrape.py`](scrape.py). Сайт: 1С-Битрикс, шаблон
Intec Universe, PHP 7.4, nginx.

Данные — референс, не инструкции. Персональных данных посетителей здесь нет:
корзина, личный кабинет, авторизация и поиск не обходились.

## Что внутри

| Путь | Содержимое |
|---|---|
| `raw/<путь>/index.html.gz` | Исходный HTML каждой страницы как есть (+ `index.meta.json`: статус, редиректы, время) |
| `md/<путь>/index.md` | Контент страницы без шапки и подвала, в Markdown, с front matter (url, title, description, type) |
| `assets/` | Оригиналы изображений из `/upload/`, CSS, JS, шрифты, иконки — пути как на сайте |
| `data/pages.jsonl` | По строке на страницу: meta и OG, h1 и заголовки, хлебные крошки, текст, ссылки, картинки с alt, формы с полями, microdata, JSON-LD |
| `data/products.json` / `products.csv` | Каталог: название, артикул, цена, наличие, бренд, категория, рейтинг, все характеристики (состав, применение, противопоказания, PV…), описание и вкладки, сертификаты, картинки. CSV — `;`, UTF-8 BOM, открывается в Excel |
| `data/catalog.json` | Разделы каталога: дерево (parent/children), товары раздела со всех страниц пагинации |
| `data/blog.json` | Статьи блога: дата, заголовок, текст, картинки |
| `data/site.json` | Сквозные элементы: логотип, телефоны, e-mail, меню шапки и подвала, внешние ссылки |
| `data/design.json` | Цвета темы, шрифты (@font-face), частые цвета и кегли из CSS |
| `data/audit.json` | Битые ссылки, дубли title, страницы без h1/description, ошибки microdata, картинки без alt |
| `data/crawl.json` | Журнал обхода: каждый URL, статус, откуда на него ссылаются |

## Объём

- 227 страниц со статусом 200: главная, 166 товаров, 17 разделов каталога
  (34 страницы с пагинацией), блог (список и 8 статей), 16 информационных
  страниц (компания, FAQ, отзывы, сертификаты, доставка, оплата, контакты,
  акции, фото, видео, тест, марафон здоровья, оферта, согласие).
- 1155 файлов ассетов, около 171 МБ: 972 изображения (включая логотип SVG), 93 CSS,
  37 JS, 53 файла шрифтов и иконочных шрифтов.
- Все 35 URL из `sitemap.xml` есть в снимке; остальные страницы найдены обходом
  ссылок (sitemap сайта неполный: в нём 16 товаров из 166).

## Что нашлось на сайте (data/audit.json)

- 13 битых ссылок (404) из статей блога на старые адреса товаров вида
  `/catalog/biologicheskie-dobavki-bady/<товар>/`: 7 в «Коррекция веса с NSP»,
  5 в «О Витамине E», 1 в «Научный консультант NSP о витамине С».
- Все 8 статей блога имеют тот же `<title>`, что и список блога.
- У 23 наборов (`/product/nabor-*`, `*-kit`) разметка schema.org `Offer` и
  `AggregateRating` стоит вне `Product`: поисковик не видит цену набора.
- Нет `h1` на главной и на `/health-marafon/`; у `/health-marafon/` нет description.
- Ссылки на соцсети в шапке и подвале ведут на корень facebook.com и
  instagram.com, а не на страницы компании.
- 201 изображение без `alt`.
- Sitemap неполный (см. «Объём»), дата последнего изменения части файлов — 2021 год.

## Ограничения

- Отзывы внутри карточек товаров сайт подгружает AJAX-ом (`intec.universe:reviews`),
  в HTML их нет. Общая лента отзывов `/company/reviews/` в снимке есть.
- Ссылки умного фильтра (`/filter/…/apply/`) только проверены на статус, их
  контент не сохранялся: это комбинации одних и тех же товаров.
- Из query-параметров сохранена только пагинация `PAGEN_*`; сортировки считаются дублями.
- Уменьшенные копии `/upload/resize_cache/…` заменены оригиналами.
- Внешние сайты (включая nsp-center.com.ua) не обходились.

## Повторить

```bash
cd references/nsp-center.ru
uv run scrape.py            # обход -> ассеты -> извлечение (кэш raw/ и assets/ переиспользуется)
uv run scrape.py extract    # пересобрать data/ и md/ без обращения к сайту
uv run scrape.py --refetch  # скачать всё заново
```

Обход идёт в 4 потока с паузой 0,2 с после каждого запроса.
